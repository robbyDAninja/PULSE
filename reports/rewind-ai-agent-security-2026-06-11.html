01
March wks 1–2

The warning phase: alarms, datasets, and scrap-wood defenses.

When collection started, agent security was mostly something people warned about. OpenAI published a dataset to harden models against prompt injection. HackerOne turned "agentic prompt injection testing" into a service. Futurism ran a story about a rogue agent triggering an emergency at Meta. The community's response was early and scrappy — first sandboxing projects, hand-rolled guards, Show HN experiments.

02
April wks 3–6

The tooling wave: defense becomes something you can install.

Big-lab research arrived — Meta's research arm published SecAlign and prompt-siren — and the open-source ecosystem answered with a rush of benchmarks and detectors: pint-benchmark, prompt-guard, PIGuard, sub-millisecond classifiers. The credential problem got named and productized. Offense kept pace with defense. And reality kept supplying case studies for why all of it mattered.

03
May wks 7–10

From tools to norms: the question changes shape.

The discourse stopped asking "is this a risk?" and started asking "how are you handling it?" — literally, on the front page of Hacker News. Sandboxes hardened into infrastructure. Security firms with reputations entered the arena. And a hygiene layer appeared for the mess agents had already made — scanners for the API keys leaked into months of chat history.

June wks 11–13

The platform phase: security ships as a default.

The big players absorbed it. Alibaba shipped OpenSandbox. NVIDIA's NemoClaw guardrails rank among the most-starred repos in the window. An Anthropic cybersecurity skills collection was the single biggest mover of the month. And — per this week's briefing — OpenAI shipped Lockdown Mode into ChatGPT itself: an agent-security primitive, delivered to consumers as a settings toggle.

The Thread
In one quarter, agent security traveled the full arc — warning → tooling → norm → platform default.

That's the same arc HTTPS took a decade to walk.

Why this matters — if you run a business

"We'll wait until it's safe" was a reasonable position in March.

The industry spent the quarter dismantling it. The guardrails that make it safe to hand an agent real work are being built into the platforms themselves — sandboxes from hyperscalers, guardrails from chipmakers, lockdown switches in consumer settings. The window where caution and waiting were the same thing is closing. Grounded hope, with receipts.
